## 关键补修证据

- A2：旧版在 IndexedDB 等待期间切号仍上传、迟到上传回写、旧 token 画板启动 repair、旧快照覆盖编辑四个场景均断言失败。补修后保留新增／删除／移动节点、提示词、手动媒体修改与聊天编辑；切号后不应用迟到结果。独立只读终审未发现新的确凿 P1/P2。
- B6：旧版 409 后发送序列多出 canonical `remote`，且普通保存会删除保存期间新出现的 `unresolved` 草稿。补修后未解决草稿暂停自动请求，只有显式重试成功才清除对应草稿；再次冲突保留最新编辑。
- B7：旧版带 `_time_format=sqlite` 时第二个 `BEGIN` 成功，未取得预期即时写锁。补修后第二连接收到 `SQLITE_BUSY`（代码 5），首连接回滚后可正常开始并提交；日期编码在时区、纳秒、UTC、零值样本中逐字一致。非法格式仍由驱动拒绝，内存库不改。
- B4：首批入口与提交用例旧版 12/12 断言失败；审计再发现异步确认过早解锁及任务返回期间切号回写，补修前 17 项中 6 项断言失败。修复后等待异步确认、同帧防重入，持久化／直连任务及元数据响应期间切号不再写日志／结果；B4 与相邻集 47/47 通过。切号前已经送达后端的任务仍属于原账号，前端不声称撤销该任务。
